# DevOps Team Project

Командный проект по дисциплине «Прикладные аспекты DevOps».

## Цель проекта

Изучение Git, стратегий ветвления и организации совместной разработки программного обеспечения.

## Участники

1. ФИО первого студента
2. ФИО второго студента
3. ФИО третьего студента

## Используемые технологии

- Git
- GitHub
- Markdown

## Описание

Участники проекта работают в отдельных ветках, создают Pull Request, выполняют Code Review и учатся разрешать конфликты слияния.
