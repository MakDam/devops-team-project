\# План тестирования



\## Цель тестирования



Проверить правильность работы с Git и GitHub.



\## Проверяемые операции



1\. Клонирование репозитория.

2\. Создание и переключение веток.

3\. Добавление и фиксация изменений.

4\. Отправка изменений на GitHub.

5\. Создание Pull Request.

6\. Объединение веток.

7\. Создание и разрешение конфликта.



\## Критерии успешного тестирования



\- Команды Git выполняются корректно.

\- Изменения сохраняются в commits.

\- Файлы доступны в репозитории.

\- Конфликт успешно разрешён.

\- История commits отображается без ошибок.
